## Featured Projects

### 1. [SQL Data Warehouse Project — End-to-End ETL \& Star Schema](https://www.google.com/search?q=https://github.com/galibhasan720/sql-data-warehouse-project-dwh)
`SQL Server` `T-SQL` `Stored Procedures` `Medallion Architecture` `Star Schema`

An end-to-end relational data warehouse engineered from raw ERP and CRM source files to business-ready analytical tables.

- **Medallion ETL Pipeline:** Built a 3-layer SQL Server warehouse (`Bronze`, `Silver`, `Gold`) integrating **6 ERP and CRM CSV files** through automated stored-procedure ingestion and cleansing.
- **Dimensional Data Modeling:** Designed a **star-schema Gold layer** of fact and dimension tables structured to analyze customer behavior, product performance, and sales trends.
- **Data Quality & Documentation:** Implemented Silver and Gold SQL validation tests to verify data integrity and authored architecture diagrams, data models, and data catalog documentation.

### 2. [Exploratory \& Advanced SQL Data Analysis — KPI Reporting \& Segmentation](https://www.google.com/search?q=https://github.com/galibhasan720/advance-data-analysis)
`T-SQL` `SQL Server` `CTEs` `Window Functions` `Reporting Views`

A structured analytical suite transforming warehouse data into executive KPIs, trend diagnostics, and customer/product segments.

- **Ordered Analytics Pipeline:** Authored a **14-script T-SQL workflow** progressing from database setup and KPI exploration (sales, orders, customers, products, quantity, average price) to production-ready reporting.
- **Advanced Analytical Queries:** Executed magnitude, ranking, time-series, cumulative, YoY, part-to-whole, and performance analyses using CTEs, joins, and window functions.
- **Reusable BI Views:** Implemented customer and product segmentation and deployed two reusable Gold reporting views (`gold.report_customers` and `gold.report_products`).
